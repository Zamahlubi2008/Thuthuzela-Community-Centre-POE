THUTHUZELA COMMUNITY CENTRE 

HOW TO APPLY
1. Make a backup copy of your original project folder first.
2. Open this ZIP. Copy the six updated HTML files into the root of your existing project folder, replacing the originals.
3. Copy the entire assets folder from this ZIP into the project root. Merge folders if asked; replace files with the same names.
4. Add inquiry.html and privacy.html to the project root (they are included here).
5. Replace the old root-level map.js with the map.js supplied here (it removes the unrelated Ikasi Youth Centre reference).
6. Copy CHANGELOG.md into your project or use it to prepare the changelog required by your lecturer.
7. Keep your original programmes.json, events.json, JPG files and README.md. Do not publish the old sitemap.xml as it contains example.org URLs; remove it until you have a real hosted domain, then generate a sitemap using that domain.

IMPORTANT
- The changelog is a draft based on technical issues found in the supplied ZIP. Add the exact Part 2 lecturer feedback and your own evidence before submission.
- The contact and enquiry forms are demonstration forms only; they validate in the browser and do not send/store messages.
- Contact details, services, map location and photos must be verified/approved before presenting the site as a real organisation's live website.
- The stylesheet was adjusted to match the supplied HTML class names. Please test all pages in a browser after copying.
